# Du Feu à la Fusée (titre de travail)

Un city builder cosy pour Joshua : une vallée qui traverse l'histoire, de l'âge de pierre jusqu'au décollage d'une fusée.

- Documentation et décisions : `kb/` (commencer par `kb/INDEX.md`)
- Images : `assets/raw/` (générations brutes) et `assets/sprites/` (objets détourés)
- Outils : `scripts/`
- Ludiworld : `ludi.json` (la fiche du jeu) est copiée par `python3 build.py --pwa docs` à la racine du site ; `src/ludi.js` est le kit Ludiworld, copié tel quel depuis https://pikifou.github.io/ludiworld/kit/ludi.js et intégré à la page. Ouvert seul, le jeu ne change pas.
