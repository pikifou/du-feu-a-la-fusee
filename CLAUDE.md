# Jeu « Civilization simplifié » pour Joshua

Avant toute tâche, lire dans l'ordre :
1. `kb/INDEX.md`
2. `kb/PROCESS.md`
3. `kb/canon/status.md`
4. `kb/canon/decisions.md`
5. le fichier du domaine concerné dans `kb/domains/`

Règles :
- La KB est la source de vérité ; un fait vit à un seul endroit (pas de copie, on référence).
- Une décision de Julien s'ajoute tout de suite en ADR dans `kb/canon/decisions.md`. Une proposition de Claude n'est pas une décision.
- En fin de session substantielle, proposer une capture dans `kb/journal/` (format `kb/_templates/_capture-session.md`).
- Le canon ne bouge hors ADR qu'en réconciliation validée par Julien.
- Pas de tirets longs dans les textes destinés à Julien.
